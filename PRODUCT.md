# Publication Workbench

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Python 3.12 standard library, SQLite, static HTML/CSS/JavaScript. No dependencies.

## Users

A single local editor preparing an invented community arts program, and portfolio readers evaluating the software.

## Product Purpose

Edit structured program content, review a specific draft revision, and explicitly publish a consistent snapshot. Search results must reach the correct published entity.

## Capabilities and Constraints

Saved draft revisions; required-field and reference validation; review gates; optimistic version checks; immutable published snapshots; self-contained HTML export. Local loopback only. No production authentication or collaboration claim. Every festival, performer, venue, and program entry is fictional.

## Operating Context

Assumption from the brief: an editor works through a short program on a laptop. The primary surface is a practical editorial tool; the export is a readable event program. User-directed execution skips interviews and browser verification.

## Product Principles

- A published program is a stable artifact.
- Review always names the revision it covers.
- Validation explains what to repair.
- Links lead to actual rendered entities.
